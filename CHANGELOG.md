# Change Log

All notable changes to the University of Idaho Theme extension will be documented in this file.

## [1.1.0] - 2026-11-12

### Added

- Positron console, Variables, data explorer, and data grid colors.
- Autocomplete, search, Git diff, diagnostics, and notebook styling.
- Semantic token colors and expanded syntax highlighting.
- An original mountain-and-code extension icon.
- Python, R, and notebook examples with dark and light editor screenshots.
- Dependency-free theme validation, including core text and syntax contrast checks.

### Changed

- Applied gold `#F1B300`, gray `#808080`, charcoal `#191919`, and white `#FFFFFF` as the core palette.
- Used neutral body text in the dark theme and darker gold-derived syntax in the light theme for readability.
- Preserved existing theme names and kept diagnostic and Git status colors distinct.

## [1.0.1] - 2026-11-12

### Changed

- Updated the extension description and search keywords for Positron and VS Code.
- Added Positron installation, local VSIX installation, and customization instructions.
- Documented the confirmed palette as a planned refresh; theme color files are unchanged.
- Updated the extension gallery banner to charcoal (`#191919`).

## [1.0.0] - 2024

### Added
- Initial release of University of Idaho Theme
- Dark theme: "University of Idaho — Black & Gold"
- Light theme: "University of Idaho — Dual Gold/White/Black"
- Comprehensive color definitions for all UI elements
- Token colors for syntax highlighting
- README with installation and usage instructions
